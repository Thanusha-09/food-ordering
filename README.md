# Food Ordering App

A food ordering application that allows users to browse food items, add items to a cart, and place orders.

## Features

- User registration and login
- Browse food items
- Search for food
- Add food to cart
- Update cart items
- Place orders
- Order history
- User-friendly interface

## Technologies Used

- Flutter
- Dart
- Firebase
- Git & GitHub
